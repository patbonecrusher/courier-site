# Courier site

Public pages for [Courier](https://patbonecrusher.github.io/courier-site/), a personal macOS
mail client for Gmail with on-device AI. These are the home page, privacy policy and terms of
service registered on the app's Google OAuth consent screen.

- Home: <https://patbonecrusher.github.io/courier-site/>
- Privacy policy: <https://patbonecrusher.github.io/courier-site/privacy.html>
- Terms of service: <https://patbonecrusher.github.io/courier-site/terms.html>

`docs/` is deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`
that touches it. The app's source lives in a separate private repository.

Keep the privacy policy truthful: update it before the app's handling of Google user data
changes (new scopes, any cloud feature).
